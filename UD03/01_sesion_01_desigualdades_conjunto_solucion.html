1Desigualdades y conjunto soluciónQué significa resolver una inecuación y cómo representar todos sus valores solución.⌄

Qué significa resolver una inecuación y cómo representar todos sus valores solución.

Comprende

La idea que da sentido

Una ecuación suele señalar un valor; una inecuación describe un conjunto de valores. Resolver 2x − 3 < 5 significa encontrar todos los números que hacen verdadera la comparación. El 4 es la frontera: a un lado se cumple y al otro no.

Aprende

La regla que debes recordar

Los signos < y > excluyen el extremo; ≤ y ≥ lo incluyen.

En la recta, un punto abierto significa que el extremo está excluido; un punto cerrado indica que está incluido.

x < a(−∞, a)
x ≤ a(−∞, a]
x > a(a, +∞)
x ≥ a[a, +∞)

El infinito siempre lleva paréntesis.

Procedimiento

Cómo resolver paso a paso

  1. Lee qué relación debe cumplirse.
  2. Encuentra el punto frontera convirtiendo temporalmente el signo en igualdad.
  3. Decide si se incluye la frontera según el signo original.
  4. Representa el intervalo en la recta numérica.
  5. Comprueba un número interior en la inecuación inicial.
Ejemplo resuelto

Modelo paso a paso

Resuelve: x + 2 < 5

  1. Calcula la fronteraCambia el signo por igualdad: x + 2 = 5x = 3.
  2. Comprueba los dos ladosCon x = 0: 0 + 2 < 5 es verdadero. Con x = 4: 4 + 2 < 5 es falso.
  3. Decide el extremoCon x = 3 se obtiene 5 < 5, que es falso: el 3 queda fuera.

Resultado: x < 3 · intervalo (−∞, 3)

Comprueba

Revisa la respuesta

  • No des un solo valor: expresa todo el conjunto solución
  • Haz coincidir desigualdad, intervalo y dibujo
  • No cierres un extremo si el signo es estricto.
2Interpretar y representar una soluciónExplicación ampliada y ejemplo resuelto paso a paso⌄
Ejemplo resuelto · Paso a paso

Para comprobar si un valor pertenece a una solución, sustitúyelo en la desigualdad original. Resolveremos x + 4 ≤ 16.

Frontera: x + 4 = 16.
Restamos 4: x = 12.
Con x = 0: 0 + 4 ≤ 16 es verdadero.
Con x = 13: 13 + 4 ≤ 16 es falso.
Con x = 12 se obtiene 16 ≤ 16, verdadero.
Solución: x ≤ 12; intervalo (−∞, 12].

El punto cerrado representa que 12 se incluye; la zona solución queda a su izquierda.

3Por qué funciona la frontera y cómo cambia el signoExplicación ampliada y ejemplo resuelto paso a paso⌄
Ejemplo resuelto · Paso a paso

Para localizar el límite, resuelve la igualdad asociada. Después vuelve a la inecuación original y prueba un valor a cada lado.

Ejemplo guiado: −2x + 1 < 5

Frontera: −2x + 1 = 5
Restamos 1: −2x = 4
Dividimos entre −2: x = −2
Prueba a la izquierda, x = −3: 7 < 5 es falso.
Prueba a la derecha, x = 0: 1 < 5 es verdadero.
En la frontera: 5 < 5 es falso.
Solución: x > −2, intervalo (−2, +∞).

También por despeje:

−2x + 1 < 5
−2x < 4
Dividimos entre −2 e invertimos el signo.
x > −2

La regla se entiende con números: −2 < 3, pero al multiplicar por −1 obtenemos 2 > −3. La frontera única y la prueba por lados funcionan cuando el coeficiente reducido de x es distinto de cero. Si la x desaparece, la comparación constante puede ser verdadera para todos los reales o falsa para todos.
